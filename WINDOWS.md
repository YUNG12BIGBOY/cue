# cue for Windows — clean local fork

This folder is a Windows build of [Blueturboguy07/cue](https://github.com/Blueturboguy07/cue)
(`v0.2.13`) with the upstream identity-evasion removed.

Requires **Windows 10 2004+ / Windows 11 x64** and **Node.js 22.12+**. No Visual
Studio or C++ toolchain is needed.

## What changed from upstream

| Upstream | This fork |
| --- | --- |
| `postinstall` renamed Electron to `MicrosoftEdgeUpdate.exe` | `postinstall` removed; Electron keeps its real name |
| PE version/company metadata forged to “Microsoft Edge Update / Microsoft Corporation” | Honest `FileDescription/ProductName/CompanyName = cue`, version `0.2.13` |
| Microsoft Edge icon copied from the local Edge install | Own cue pinwheel icon generated by `scripts/make-cue-icon.ps1` |
| `app.setName('MicrosoftEdgeUpdate')`, `process.title = 'MicrosoftEdgeUpdate'`, window title “Microsoft Edge Update” | `cue` everywhere |
| `scripts/rename-electron.js`, `apply-icon.js`, `build-icon.js` | deleted |
| CRLF checkout broke 36 source-text tests | `.gitattributes` + LF-normalized tree; **555/555 tests pass** |

Everything else — screen capture, microphone + system-audio listening, local
whisper.cpp transcription, providers, meeting memory, shortcuts — is upstream
code. `setContentProtection` / `WDA_EXCLUDEFROMCAPTURE` is kept as the
documented Windows screen-share privacy feature; it is not a process disguise.

## Build

```powershell
npm.cmd install
npm.cmd test
npm.cmd run dist:win
```

Outputs:

| Path | What it is |
| --- | --- |
| `dist\win-unpacked\cue.exe` | runnable unpacked app |
| `dist\cue-win-x64.exe` | per-user NSIS installer (~98 MB) |

The installer is **unsigned**, so SmartScreen may show an “Unknown publisher”
warning on first run. Install it for the current user only; no elevation prompt.

To rebuild just the icon:

```powershell
npm.cmd run icon:win
```

## Run

From source:

```powershell
npm.cmd start
```

Or launch the built app:

```powershell
.\dist\win-unpacked\cue.exe
```

Quit with **Ctrl+Shift+X**; cue intentionally has no taskbar button.

## First use

1. Grant microphone access when Windows asks (Settings → Privacy & security →
   Microphone → let desktop apps access the microphone).
2. Open Settings (`Ctrl+,`) and add a provider key — OpenAI, Anthropic, Gemini,
   OpenRouter, Dahl, Azure AI Foundry, DeepSeek, Groq or any OpenAI-compatible
   endpoint — or use the publik gateway if your build has its token.
3. Optional local transcription: **Settings → Audio → Local**, then download a
   model (`base.en` is a good default).
4. Chat text size and boldness live in **Settings → Appearance**. Both sliders
   apply live, are saved locally, and only affect the conversation — size scales
   your messages, cue's answers and code blocks, while boldness keeps your own
   bubble one step heavier than cue's answer.
5. **Clear chat** sits beside **Transcription history** in the composer. It
   empties the conversation only; the transcription history and the input box
   are separate and stay untouched. An answer still streaming when you clear is
   dropped instead of painting itself back into the panel.
6. **Settings → Appearance → Chat auto-scroll** picks how quickly the answer
   area follows new text: **Off** (never move on its own), **Slow** (220 px/s),
   **Normal** (600 px/s, the default), **Fast** (1400 px/s) or **Instant**
   (jump straight to the newest line). Slow, Normal and Fast glide frame by
   frame; the level is saved locally and applies to the next answer. Scrolling
   up by any means pauses following, and returning to the bottom resumes it —
   except with **Off**, which leaves the view where you put it.

No account is required for bring-your-own-key use, and cue has no telemetry.

## Providers added in this fork

| Provider | Base URL | Default fast / smart | Notes |
| --- | --- | --- | --- |
| **Dahl** | `https://inference.dahl.global/v1` | `zai-org/GLM-5.3-Flash` / `deepseek-ai/DeepSeek-V4-Flash-0731` | Text only. Models reason; cue adds thinking headroom and strips inline `<think>` blocks. No screenshots, no STT. |
| **OpenRouter** | `https://openrouter.ai/api/v1` | `google/gemini-3.8-flash` / `anthropic/claude-sonnet-5.5` | Any live OpenRouter id can be typed in the Fast/Smart fields. Both defaults accept images. |

Both are fixed endpoints (not user-editable), so a mistyped base URL can never
send the key to another host. Model ids were checked against the live catalogs
on 2026-11-06. Dahl's balance is visible at `GET /tokens/current`; cue uses that
endpoint for the free startup key check.

Dahl and OpenRouter serve chat only. For listening, use the bundled local
whisper.cpp (`Settings → Transcription → Local`) or add an OpenAI / Gemini /
Groq / Deepgram key.

## Always on top

The overlay is created with `alwaysOnTop`, `WS_EX_TOPMOST` and
`WS_EX_TOOLWINDOW`, and every 1.5 seconds it re-asserts both its topmost flag
and its z-order (`moveTop()`). It also re-asserts when it is shown, restored,
focused, or another window takes focus. `moveTop()` changes z-order only — it
never steals focus — so the app underneath stays fully usable while cue stays
overlaid above normal windows, browsers, and borderless-fullscreen software.

Two limits come from Windows itself, not cue: exclusive-fullscreen games using
DirectX fullscreen bypass the desktop compositor, and the secure desktop (UAC,
lock screen) cannot be overlaid by any normal desktop window.
